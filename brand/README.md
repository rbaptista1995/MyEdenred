# Branding

This directory holds brand assets for the MyEdenred integration.

## Current status

No logo/icon is shipped with this repository. The MyEdenred name and
visual identity are trademarks of Edenred, so no brand asset is invented
or copied here. The integration works without local branding.

## What is required for a HACS default-repository submission

Branding for integrations in the HACS default repository is provided
through the [hacs/branding](https://github.com/hacs/branding) repository,
not through this repository. To have a logo shown in HACS:

1. Open a PR against `hacs/branding` adding `logos/myedenred.png`
   (square PNG, transparent background, at least 128×128 px).
2. Only use artwork you are entitled to use. If no licensed artwork is
   available, submit without a logo — a logo is not a blocking
   requirement for HACS inclusion.

## Optional local assets

If the repository owner obtains rights to official artwork, place it
here as:

- `icon.png` — square icon (recommended 512×512 px, transparent PNG)
- `logo.png` — wide logo variant

Do not commit unofficial reproductions of the Edenred/MyEdenred brand.
